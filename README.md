# 🏫 Информационная система детского сада

Курсовой проект по дисциплине «Базы данных» и «Шаблоны разработки программного обеспечения».

## 📝 Описание

Информационная система для автоматизации учета данных детского сада:
- Учет детей и групп
- Учет родителей (с возможностью привязки нескольких детей)
- Учет воспитателей и закрепленных за ними групп
- Ведение посещаемости
- Финансовый учет платежей

## 🛠️ Технологии

- **Backend:** Python 3.12, Flask
- **Database:** PostgreSQL, SQLAlchemy ORM
- **Frontend:** Bootstrap 5, Jinja2 templates
